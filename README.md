# Flappy keIWs

Flaxa mellan staplarna! En variant av Flappy Bird i pixelstil, med keIWs.

Spela på **https://flappy.keiws.com** – tryck på skärmen (eller
mellanslag/pil upp på datorn) för att flaxa. På mobilen kan den installeras
med "Lägg till på hemskärm" och fungerar då offline.

Den senaste utvecklingsversionen finns på
https://isak-wallo.github.io/flappy-keiws/ och kan vara ostabil.
